# Crimson Shrine portfolio

This is a dependency-free static portfolio ready for GitHub Pages.

## Customize

1. Edit the `portfolio` object in `script.js` for the name, bio-adjacent portfolio data, skills, projects, and links.
2. Optional media files live beside `index.html`:
   - `avatar.jpg`
   - `background.mp4`
   - `ambient.mp3`
3. Push the contents of this directory to a GitHub repository and enable **Pages → Deploy from a branch → main → /(root)**.

The site deliberately has CSS visual fallbacks, so all media files are optional. Use only media you own or are licensed to publish.
